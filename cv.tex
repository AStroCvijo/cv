\textbf{CodeRAG} $|$ \textit{RAG, LangChain, OpenAI, Hugging Face, CLI} \hfill \href{https://github.com/AStroCvijo/coderag}{\textbf{GitHub}}
\begin{itemize}[noitemsep,topsep=2pt,leftmargin=*]
    \item Created a \textbf{QA system for codebases} with a customizable RAG pipeline supporting top-k retrieval, configurable chunk sizing, and multiple embedding backends (OpenAI, Hugging Face).
    \item Improved \textbf{Recall@10 from 63.7\% to 88.8\%} through iterative enhancements: LLM-generated code summaries, larger embedding models, enriched metadata (file paths, function/class lists), and chunk size tuning.
    \item Built a \textbf{full agentic generation graph} on top of retrieval: retrieval grader (filters irrelevant docs), question re-writer (query transformation on retrieval failure), answer generator, hallucination grader, answer grader, and an out-of-scope handler — with conditional edges routing between nodes based on grading outcomes.
    \item Built a \textbf{CLI and evaluation script}; designed a \textbf{modular architecture} for easy integration of new models and vector stores.
\end{itemize}
